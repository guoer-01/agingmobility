# Overview
This code supports the results presented in a research paper "**Assessing Revealed Service Accessibility for Aging Populations across the US**." The first part relates primarily to the results in the Main Text (including sections 2.1-2.6), and the second part is for the Supplementary Information (SI) sections. The detailed correspondence is shown in the table below.

| code  | section in the Main Text  | section in the SI  |
|:------|:------:|:------:|
| [Analyses_Mobility_Pattern](/Analyses_Mobility_Pattern.ipynb) | 2.1 |  |
| [Analyses_Distribution_A](/Analyses_Distribution_A.ipynb) | 2.1 | A.8 |
| [Analyses_Regression](/Analyses_Regression.ipynb) | 2.3 |  |
| [Analyses_Fairness_Index](/Analyses_Fairness_Index.ipynb) | 2.4 |  |
| [Analyses_Aging_Services](/Analyses_Aging_Services.ipynb) | 2.5 | A.9 |
| [Analyses_Projection](/Analyses_Projection.ipynb) | 2.6 | A.10 |
| [SI_Part1](/SI_Part1.ipynb) |  | A.3, A.5, A.7 |
| [SI_Part2](/SI_Part3.ipynb) | | A.12 |
| [SI_Part3](/SI_Part3.ipynb) |  | A.6 |

Note that for the code to work properly, please put the **[data](/data)** folder-proof in the same file directory as the codes, or modify the file paths in the codes.



# System requirements
